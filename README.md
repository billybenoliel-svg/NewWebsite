# Araya.ca

Static multi-page website for Araya.ca, an Ontario apartment rental brand.

## Pages

- `index.html` - homepage
- `cities.html` - city browsing page
- `buildings.html` - building listings page
- `contact.html` - contact and leasing page

## Shared files

- `styles.css` - site design and responsive layout
- `data.js` - city and building listing data
- `app.js` - shared header, footer, filters, building cards, and interactions

## Deployment

This is a plain static website. It can be deployed directly on Vercel with no build command.
